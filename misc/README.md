# Miscellaneous Files

This folder contains helper scripts, tools, and non-essential files for the AWS Connect Exporter project.

## Scripts
- `build.sh` - Build script that outputs binaries to bin/ folder
- `debug-mock-connection.sh` - Helper for debugging mock API connections
- `fix-lab-paths.sh` - Lab server path fixing utility
- `fix-lab-server-http.sh` - Lab server HTTP configuration helper
- `run-with-mock-api.sh` - Script to run exporter with mock API
- `setup-lab-server.sh` - Lab server setup automation
