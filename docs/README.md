# Documentation Overview

This folder contains simple step-by-step guides for using the AWS Connect Exporter and the mock API.
Each guide is written in very plain language.

- [quick-start.md](quick-start.md) - run everything locally in minutes.
- [mock-api-howto.md](mock-api-howto.md) - learn how to start the mock API.
- [debugging-guide.md](debugging-guide.md) - check logs and enable debug output.
- [adding-metrics.md](adding-metrics.md) - add new metrics to the exporter and mock API.

For more advanced topics see:
- [aws-connect-setup.md](aws-connect-setup.md)
- [development-with-mock-api.md](development-with-mock-api.md)
- [TESTING.md](TESTING.md)
